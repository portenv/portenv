# Milestone 0.1: repository, CI and protocol scaffold

Date: 2026-10-07

## What exists now

- Go workspace (`go.work`) with two modules: `core` and `proto/gen/go`.
- Four commands that build and report their version: `portenvd`, `portenv-runner`, `portenv-agent`, `portenv`. `portenv-agent` builds static for linux/arm64 and linux/amd64.
- Protocols: `portenv.types.v1` and `portenv.driver.v1` fully defined; `portenv.daemon.v1` and `portenv.agent.v1` unstable skeletons. Generated Go code is committed.
- `core/driver.Driver` mirrors `DriverService` (signatures only); a test fails if their methods or enums drift apart.
- `core/internal/boundary` fails the build if code outside `core/driver/` imports an engine SDK or runs an engine CLI (`docker`, `container`, `podman`, …).
- Swift placeholder package for the Apple Containerization shim, with one test.
- CI (`.github/workflows/ci.yml`): Go on Linux amd64 and arm64, static agent, protocol freshness, Swift on macOS 26, full-history secret scan.
- Apache-2.0 LICENSE, NOTICE, SPDX headers checked by `make lint`. ADRs 0001 and 0002.

## Demo

```sh
make check            # build, test, lint, proto-check, agent-linux, secrets, swift-test
./bin/portenvd        # portenvd <version> (<commit>)
file bin/linux-*/portenv-agent   # both "statically linked"
```

## Notes

- A single `tools/go.mod` for all developer tools did not work (actionlint and golangci-lint need conflicting dependency versions); tools are pinned in the `Makefile` instead. See ADR 0002.
- First CI run on GitHub (run 37636911559, 2026-10-07): all six jobs green: Go amd64 and arm64, static agent, protocols, Swift on macOS 26, secret scan.
- Repository settings: public; secret scanning with push protection on; `main` accepts pull requests only, with all six checks required and no admin bypass.
