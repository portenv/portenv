Rules: the SSH door for agents ships off and labelled PREVIEW until the outside review (owner, R-0102); turning it on asks once more with the same sentence. Revoke takes effect at once and says so. Make New Key… walks through the recovery-key screen again and re-wraps every workspace’s saves; the old key stops working only when that finishes. Remove (server) never deletes anything of the person’s. Every row is one VoiceOver element: label, state, then the line under it.
