Command blocks · states, actions, the sticky header and links (for lane A after 1.2c)

Every command in a tab becomes a block: who ran it, the command, how it ended and when. Built on ADR 0020’s per-tab terminal and its OSC 133 marks. The happy path is on main-window; this board adds the other states.

States: a finished block that succeeded folds to its header once it scrolls off the latest screen (click to unfold); a failed block stays open with its exit code in red; a running block shows elapsed time and a blue edge; long output keeps the first and last 20 lines with “Show All Output”. Who ran it: the avatar is the author portenvd records (ADR 0020 §3/§4), never what the program says. Actions show on hover and by keyboard (⌘↑/⌘↓ move between blocks; ⌥⌘C copies the selected block’s output; Run Again asks first if the command came from an agent). Sticky header: scrolling inside a long block keeps its header at the top with “↑ Top of block”. Links: hover shows the real destination in a tooltip and the state line; only http/https, only on ⌘-click (R-0134). Answer card: as on main-window; answering in the terminal always works. VoiceOver: each block is a group: “Grok Bot ran npm test -- retries, failed, exit 1, 8.4 seconds”, rotor to move between blocks. Update prompt (Sparkle’s standard window): title “A new version of Portenv is ready”, body “Portenv 0.3.0 is available; you have 0.2.0. Your workspaces keep running while it updates; open windows reopen after.”, buttons Install and Relaunch (default) / Later / Skip This Version, release notes below.
