Add a Server · the 2.9 wizard (a sheet from Settings › Servers and from Move To ▸ Add a Server…)

Four steps, no terminal: Where, Check, Set up, Ready. When someone else sets up the server (a teammate, an admin, or later a Portenv-hosted test server), the person starts with “Someone is setting one up for me”: Portenv makes a key just for that server and they send its public half. The address, user and fingerprint come back later, and they continue from Settings › Servers (frames 2–3). In-app copy never mentions Portenv test servers until that option is live. Nothing is installed until every check passes, and every failure says what to do.

Rules: the host key is shown and confirmed on first contact and pinned after (a change stops everything, with its own alert). Keys Portenv makes live in the Keychain, one per server. Check never changes the server. Optional hardening is offered, never forced: password logins stay on unless the person ticks the box (Portenv test servers have them off from the start). Set up keeps going if the window closes and reports through a notification. Servers show by name everywhere (GUIDELINES §2). VoiceOver: each check row reads as one element ("Can’t reach ghcr.io, needs fixing: …"); the step bar reads "Step 2 of 4, Check".
