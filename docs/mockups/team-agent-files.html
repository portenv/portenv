What it shows: the agent’s home, /home/<agent>, private to that agent (R-0234): its files and folders, their size, who added them (you, the agent, or the agent file’s home_seed on first start) and when. Adding: drop files or folders on the list or the agent’s row, or Add Files…; the drop target names what will be added and its size. Files are copied into the workspace as that agent; nothing on this Mac is linked. Size and quota: the bar shows what’s used of the agent’s limit; it turns red when full, with the reason, what wasn’t added and the next step. The size counts toward the workspace’s. File names an agent chose are plain text. VoiceOver: the list is a table; the bar reads “212 MB of 1 GB used”.
