Link GitHub to acme-api

Linked as @your-name

acme-api can now clone, pull and push wherever your GitHub account can, just as on your Mac, and you can clone more repositories into it at any time. The login lives in the box’s encrypted home and moves with it.

Agents working in this box can use this login too, with the same access as you. The inspector shows it under Who’s here, with Sign Out of GitHub.

This isn’t a Portenv account. Portenv never sees or keeps the GitHub login.
