What it shows: the agent’s home, /home/<agent>, private to that agent (R-0234), with each item’s size. Adding: drop files or folders on the section or the agent’s row, or Add Files…; the drop target names what will be added and its size. Files are copied into the workspace as that agent. Quota: what’s used of the agent’s limit; red when full, with what wasn’t added and the next step. The size counts toward the workspace’s. File names an agent chose are plain text.
