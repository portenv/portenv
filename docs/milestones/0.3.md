# Milestone 0.3: sync package

Date: 2026-10-07

## What exists now

- `core/sync`: `Open`, `Init`, `Resume` (the five resume rules, take over), `Save` (autosave, save point, release), `Lease`, `History`, `Forget` (retention), on top of a small restic wrapper. Design notes: ADR 0004.
- Invariants enforced in code: no save of an empty home; no restore over a home that may hold unsaved changes; a save counts only once its snapshot is listed and the machine state records it; saving over a changed lease needs confirmation and keeps the other version.
- restic 0.19.1 pinned in the Makefile and installed into `bin/`; the repository password reaches restic through a pipe, never disk or environment.

## Tests (all against real restic repositories)

- One test per resume rule, plus: local changes on top of the newest save, an existing home with an empty repository, lost machine state.
- One test per invariant, plus a save that finished after `portenvd` was killed (not a conflict).
- Leases: snapshot conventions, only the newest snapshot carries `active:`, stale after 10 minutes but never released automatically, take over moves the lease.
- Crash safety: restic killed at 100, 300 and 700 ms into a 40 MB save; `restic check` passes and the next save holds all 2001 files.
- Model test: two machines, 5 seeds × 30 random steps of edits, autosaves, closes and opens with take over; after every step every edit ever made is in a home or a snapshot.
- Mutation check: removing the orphan save is caught by the restore guard; removing both is caught by the rule 4 test.

## Demo

```sh
make test                                  # includes core/sync, about 2 minutes
go test ./core/sync -run Budget -v         # 5 MB change saved in ~2.5 s, same-machine resume ~1.2 s
```

## Notes

- Every restic call costs about 0.5 s of key derivation, so the sync tests run in parallel, one repository each.
- The performance budgets are met against a local repository. The Phase 0 gate item stays open until they are measured against remote storage (e2e harness: MinIO, SFTP).
- Where restic runs relative to the box (the home is inside a container volume or VM disk) is decided with `MountHome` in milestone 0.4.
