If you move it to this Mac now:it starts from the 14:58 save. Anything done on Test server after that isn’t lost: when Test server comes back, Portenv keeps it as a separate save you can open.

Or wait: Portenv keeps trying Test server and tells you when it answers.

Rules: the confirmation names every running command that will stop; with none, it says "Nothing is running." Defaults: Move on the confirmation, Connect on the lease sheet. On the stale sheet the default is Move to This Mac only when the last save is under an hour old; older than that, Keep Waiting is the default. The person never meets the word "lease": taking over is "Move it to this Mac". Look opens the latest save in a window marked "Read-only · from 14:58" where nothing can be typed. Every sheet: Escape cancels, Return is the default, VoiceOver reads title, body and the warning box in that order.
