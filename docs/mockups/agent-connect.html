Grok Bot’s access ends in 10 minutes

At 22:00 it’s disconnected and can’t reconnect without asking again. Anything it’s running keeps its output in the tab.

Access never goes past 24 hours from approval. To end it now, use Revoke in Who’s here or Settings › Agents.

Rules: the approval sheet has no default button, so Return never approves a code by accident. Deny closes the door. A second request while the sheet is up is refused and noted in Who’s here. Every grant, extension and revoke goes into the workspace’s history (who, when, what access). VoiceOver reads the code digit by digit. The expiry shows everywhere the agent appears.
